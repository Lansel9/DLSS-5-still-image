Переносимая сборка для Windows x64: **распакуйте ZIP и запустите DLSSNR.exe**.

Python, PyTorch и CUDA Toolkit устанавливать не нужно. Для обработки необходимы
NVIDIA RTX и совместимый драйвер NVIDIA. Все компоненты включены в архив;
интернет после распаковки не требуется.

В приложении доступны:

- выбор файла и разрешения;
- стили 0/1/2, интенсивность, Local Tone/Structure и автоматическая маска;
- OptiX 3.0 и Intel OIDN, до/после NR, регулируемая сила;
- сравнение линией мышью, зум, перемещение и масштаб100%;
- история генераций с датами и параметрами, общая и по текущему файлу.

Выход — RGB PNG. Масштабирование выполняется Lanczos, затем один проход native NR.
SR/Boost, EXR/HDR и внешние маски в эту версию не включены.

Локально проверены RTX3090/595.97, обработка4K, оба денойзера и перенос папки.
Все конфигурации других компьютеров не проверялись. Это предварительная сборка.

Скачайте ZIP из Assets ниже, полностью распакуйте и откройте DLSSNR.exe.
Исходные Source code ZIP/TAR предназначены для разработки и не содержат runtime.
Проверка целостности: SHA256SUMS.txt. Инструкция также находится внутри архива.
