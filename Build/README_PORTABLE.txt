DLSSNR Portable — Windows x64 — 0.0.0

1. Распакуйте ВСЮ папку DLSSNR-Portable из ZIP в обычную папку с правом записи.
2. Запустите DLSSNR.exe. Запускать приложение внутри окна ZIP нельзя.
3. Выберите изображение, разрешение и параметры, нажмите «Обработать».

Устанавливать Python, PyTorch, CUDA Toolkit или библиотеки вручную не нужно.
Всё необходимое включено; после распаковки интернет для обработки не требуется.
Необходимы Windows 10/11 x64, видеокарта NVIDIA RTX и совместимый драйвер NVIDIA.
Нативный режим проверен на RTX 3090 / драйвер 595.97. Другие конфигурации
требуют проверки на компьютере получателя; работа на AMD/Intel GPU не заявлена.
Начните с 2K/4K. Предел большого кадра зависит от свободной памяти видеокарты.

Результаты и история сохраняются в Results рядом с программой; другую папку
можно выбрать в интерфейсе. Параметры сохраняются в App/preferences.json.
Для передачи исходной чистой сборки используйте ZIP, а не свою папку с историей.
Для переноса на другой компьютер закрывайте программу и копируйте всю папку.

Сравнение: перетаскивание вертикальной линии, зум колесом, ЛКМ/СКМ для сдвига,
кнопка «100%». История справа и параметры готового результата сворачиваются.
Денойзер: OptiX 3.0 либо Intel OIDN; до/после DLSSNR, сила 0–1.
NR: один проход, стили 0/1/2, интенсивность 0–1, Local Tone/Structure 0–2.
Связь структуры кожи либо отдельная сила 0–0.99. Нативный движок не имеет Seed
и не выполняет NR на CPU. Результат может отличаться от прежнего PyTorch-порта.
Масштабирование выбранного разрешения — Lanczos; DLSS SR в эту сборку не включён.

Если окно не открылось, запустите DLSSNR.cmd; подробности — launch.log.
Если обработка не завершилась, журнал и подтверждение движка находятся в папке
конкретной генерации (log.txt, native-worker-*.log, native-receipt.json).
Необработанный кадр при отказе NR не выдаётся за успешный результат.

Компоненты: Python Standalone Builds (Astral), NumPy, Pillow, native worker
dlss5-video-player 0.26.2, NVIDIA/NGX runtime 310.8.SF-v2, ReShade/RenoDX,
FFmpeg, NvidiaAIDenoiser 3.0, Intel OIDN 2.5.1. Уведомления и лицензии
сохранены в Python, Runtime/Native и Reference. Это экспериментальная сборка.
