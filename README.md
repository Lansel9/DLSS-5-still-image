# DLSS 5 Still Image — приложение для Windows

Обработка отдельных изображений через DLSS Neural Rendering с настройками стиля,
тона и структуры, денойзерами и сравнением результата с оригиналом.

## Скачать и запустить

**[Скачать готовую сборку Windows x64](https://github.com/Lansel9/DLSS-5-still-image/releases/latest)**

1. В разделе Releases скачайте `DLSSNR-Portable-0.0.0-Windows-x64.zip` — около **353 МБ**.
2. Полностью распакуйте папку `DLSSNR-Portable` в удобное место с правом записи.
3. Запустите **DLSSNR.exe**.
4. Выберите изображение, разрешение и параметры, нажмите **«Обработать»**.

Установка Python, PyTorch, CUDA Toolkit и дополнительных библиотек не требуется.
В комплект включены собственный Python и все используемые компоненты. После
распаковки интернет для обработки не нужен. Папка занимает примерно **700 МБ**.
Запускайте приложение из распакованной папки, а не внутри окна ZIP.

## Требования

- Windows 10/11 **x64**.
- Видеокарта **NVIDIA RTX** и совместимый драйвер NVIDIA.
- Достаточно свободной видеопамяти для выбранного разрешения; начните с 2K или 4K.

Сборка проверена на **RTX 3090, драйвер 595.97**: реальная обработка 4096 × 3072,
изменение настроек и оба денойзера до/после NR. Проверен перенос в папку с пробелами
и кириллицей. Отдельный компьютер получателя и все серии RTX не проверялись.
Поддержка обработки NR на CPU, AMD и Intel GPU в этой сборке не реализована.

## Возможности

- Выбор PNG/JPEG и других форматов, поддерживаемых Pillow.
- Исходный размер, 2K/4K/5K/6K/8K или своя длинная сторона с сохранением пропорций.
- Стили 0/1/2, интенсивность 0–1, Local Tone и Local Structure 0–2.
- Структура кожи: специальное значение −1 либо отдельная сила 0–0.99; автоматическая маска.
- **OptiX 3.0** или **Intel OIDN 2.5.1**: включение, до/после DLSSNR, сила 0–1.
- Сравнение перетаскиванием вертикальной линии прямо на изображении.
- Зум колесом мыши, перемещение изображения ЛКМ/СКМ и масштаб **100%**.
- История всех генераций и отдельно текущего файла, дата и сохранённые параметры.
- Скрываемые история и параметры результата, остановка обработки.

Результаты по умолчанию сохраняются в **Results** рядом с программой. Для каждого
запуска создаётся отдельная папка: вход, результат, миниатюра, параметры и журнал.
Исходный файл не перезаписывается. Папку сохранения можно изменить в интерфейсе.

## Как устроена обработка

Это экспериментальная сборка на **нативном NVIDIA NR**, без PyTorch в поставке.
Изображение приводится к выбранному размеру методом **Lanczos**, после чего выполняется
один проход NR. Денойзер при включении работает до или после NR.

DLSS SR, многопроходная обработка и режим Boost в эту версию не включены. Seed в
нативном интерфейсе отсутствует. Обрабатывается отдельный 8-битный RGB-кадр;
выход — RGB PNG. EXR/HDR, альфа-канал и пользовательские Albedo/Normal/маски сцены
не передаются в NR. Автоматическая маска — внутренний параметр модели.

Эффект зависит от исходника, размера и параметров. Изменения света и фактуры
не гарантируют восстановления точных утраченных деталей. Результат может отличаться
от PyTorch-порта. При отказе NR приложение показывает ошибку и не подменяет
успешную обработку исходным кадром.

## Если возникла ошибка

- Проверьте, что извлечён весь архив и папка доступна для записи.
- Попробуйте меньшее разрешение и освободите память видеокарты.
- Если окно не открылось, запустите `DLSSNR.cmd`; журнал запуска — `launch.log`.
- Журнал задания — `Results/<генерация>/log.txt`; подтверждение нативного NR —
  `native-receipt.json`, подробности движка — `native-worker-*.log`.

## Исходники и сборка

`App/` содержит интерфейс и обработку; `Build/` — подготовку компонентов, сборку и
упаковку. Тяжёлые зависимости и пользовательские изображения в Git не хранятся.
Обычному пользователю нужен архив из **Releases**.

Для сборки на Windows с Python 3.11:

```powershell
python Build/prepare_release_components.py
python Build/prepare_python.py
python Build/build_portable.py
```

Последняя команда выведет папку в `Dist`. Для упаковки:

```powershell
python Build/build_portable.py --package "Dist/<дата>/DLSSNR-Portable"
```

Скачиваемые компоненты закреплены версиями и SHA-256. GitHub Actions повторяет эти
шаги для публикации релиза; в облачной сборке GPU-инференс не выполняется.
